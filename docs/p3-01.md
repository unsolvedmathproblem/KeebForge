# P3-01 — Nhận nền tảng và Model — 30/10/2026

Đã đối chiếu schema 8 bảng, Account/DBContext/AuthFilter/layout P1 và bàn giao P2.
Source hiện tại có đủ ProductDAO.getActiveProducts(), ServiceDAO.getById(),
WorkshopService, Product và ServiceReview dùng chung; không có phụ thuộc P2 còn thiếu.
DBContext tiếp tục mở/đóng connection từ cấu hình local hiện có, không đổi schema/seed.

## Model và getter dùng cho JSP

Mỗi property có getX/setX theo camelCase, không getter alias hay enum trạng thái.

| Model | Property | Kiểu |
| --- | --- | --- |
| Order | orderId, accountId, serviceId | int |
| Order | serviceNameSnapshot, contactName, contactPhone, deviceDescription | String |
| Order | customerNote, orderStatus, adminNote | String (note có thể null) |
| Order | servicePrice, totalAmount | BigDecimal |
| Order | preferredDate | LocalDate, nullable |
| Order | createdAt, completedAt | LocalDateTime (completedAt nullable) |
| Order | details | List<OrderDetail>, khởi tạo list rỗng |
| Order | review | model.ServiceReview của P2, nullable |
| OrderDetail | orderDetailId, orderId, productId, quantity | int |
| OrderDetail | productNameSnapshot | String |
| OrderDetail | unitPrice | BigDecimal |
| OrderDetail | subtotal | Getter tính unitPrice × quantity, không setter/cột SQL |

Đối tượng OrderDetail mới chưa có unitPrice trả subtotal = BigDecimal.ZERO;
dữ liệu đã lưu có UnitPrice NOT NULL. JSP sau này dùng `${order.totalAmount}`,
`${order.details}`, `${detail.subtotal}`, `${order.review.rating}` và money.tag P1;
text từ DB phải escape bằng c:out. Chưa tạo JSP ở P3-01.

ServiceReview giữ nguyên getter P2: reviewId, orderId, rating, comment,
createdAt (LocalDateTime), fullName (JOIN UserAccount), không tạo model thứ hai.

## Query đọc cơ bản

- `getOrdersByAccount(int accountId)`: WHERE AccountID bằng PreparedStatement;
  caller phải lấy accountId từ session.user. Không có route xem đơn ở bước này.
- `getAllOrders(String status)`: dành cho caller đã kiểm tra ADMIN; null/rỗng/trắng
  lấy tất cả, còn lại chỉ chấp nhận PENDING/PROCESSING/COMPLETED/CANCELLED.
  Status khác ném IllegalArgumentException, không ghép trực tiếp vào SQL.
- Danh sách sắp CreatedAt DESC, OrderID DESC. Nạp details và review sau khi đóng
  ResultSet cha, không yêu cầu SQL Server MARS. Đọc tên/giá snapshot và TotalAmount
  đã lưu, không thay bằng giá catalog hiện tại.
- Helper đọc chi tiết/review là private, chỉ nhận ID từ kết quả query cha.
  Đơn không có linh kiện trả details rỗng, chưa có review trả null.
- DAO kế thừa DBContext, truyền SQLException cho caller, đóng statement/result
  bằng try-with-resources. Không giữ connection/DAO trong field Servlet.

Đây là query cơ bản cho quy mô bài tập: 1 query list + 2 query con cho mỗi đơn,
chưa phân trang hoặc tối ưu thành batch. Không tạo method ghi rỗng cho bước sau.

## Kiểm tra lại trên máy hiện tại

Build từ thư mục project bằng Ant của NetBeans 17 và JDK 17:

```powershell
& 'C:\Program Files\NetBeans-17\netbeans\extide\ant\bin\ant.bat' '-Dj2ee.compile.on.save=false' clean dist
New-Item -ItemType Directory -Path build/verify-p301 -Force | Out-Null
& 'C:\Program Files\Java\jdk-17\bin\javac.exe' -encoding UTF-8 -cp 'build/web/WEB-INF/classes;web/WEB-INF/lib/*' -d build/verify-p301 test/VerifyP301.java
& 'C:\Program Files\Java\jdk-17\bin\java.exe' '-Dfile.encoding=UTF-8' '-Dkeebforce.db.config=config/db.properties' -cp 'build/verify-p301;build/web/WEB-INF/classes;web/WEB-INF/lib/*' VerifyP301
```

Chỉ chạy lệnh java nếu javac thành công. Có thể thay đường dẫn config bằng file
local của máy bạn; không chia sẻ credentials. Nếu dùng Windows auth, cấu hình
java.library.path tới DLL JDBC đúng phiên bản theo setup.md.

`test/VerifyP301.java` là kiểm tra console JDBC thật, không cần JUnit/Maven;
không nằm trong src/java/web nên không đóng WAR. Dùng account/catalog seed sẵn có,
chèn tạm 4 đơn (4 trạng thái), 3 chi tiết, 1 review trong **cùng transaction** với
query kiểm tra; luôn rollback trong finally. Không DELETE fixture hay UPDATE seed.
SQL Server có thể tiêu thụ số IDENTITY sau rollback, ID không cần liên tiếp.

Kết quả: **22/22 kiểm tra đạt**, gồm owner A/B, owner không có đơn, 4 bộ lọc,
status không hợp lệ, thứ tự, đầy đủ field Unicode/date/null, snapshot, subtotal,
tổng 2.050.000, đơn 0 linh kiện, review dùng Model P2, rollback và đóng connection.
Trước/sau fixture, số dòng 8 bảng giữ nguyên 3/3/5/10/4/0/0/0.

Build mặc định `clean dist` thành công, biên dịch 21 class production trên Java 17.
Thử thêm `-Dcompile.jsps=true` phát hiện Jasper do Ant task của NetBeans 17 nạp
báo `PWC6309: Illegal compilerSourceVM: 17`. Đây là đường kiểm tra tùy chọn,
không đổi metadata để xử lý trong bước Model. Đã biên dịch trực tiếp toàn bộ JSP
bằng `org.apache.jasper.JspC` từ **Tomcat 10.1.59**, source/target 17,
classpath thêm `ant.jar`, 3 JAR runtime và class ứng dụng: **0 lỗi**.
Output kiểm tra nằm trong build/verify-jsps, không đưa vào WAR.
Lệnh build mặc định trong hướng dẫn trên không bật tùy chọn gây lỗi này.
