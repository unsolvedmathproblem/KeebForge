# P3-05 — Admin xử lý đơn và dashboard — 30/10/2026

Đăng nhập ADMIN rồi chọn **QL Đơn** hoặc **Tổng quan**. Dùng AuthFilter, session
Account, DBContext, layout và money.tag hiện có của P1. Không thêm thư viện,
service layer, DTO, enum hoặc schema mới.

## Route và hành vi

- GET `/admin/orders?status=` đọc `OrderDAO.getAllOrders`, hiển thị mọi owner,
  liên hệ, dịch vụ/giá snapshot, thiết bị, ngày, ghi chú khách và chi tiết linh kiện.
  Bộ lọc chỉ nhận rỗng hoặc PENDING/PROCESSING/COMPLETED/CANCELLED; giá trị sai hay
  trùng tham số trả 400. Lỗi DB trả 503, không hiện list rỗng giả.
- POST `/admin/orders` nhận action=status, orderId, newStatus; hoặc action=note,
  orderId, adminNote. Cả hai có csrf P1; hidden status chỉ giữ bộ lọc để redirect,
  được validate trước khi ghi. Không nhận redirect URL, owner, giá, thiết bị hoặc
  chi tiết từ form để cập nhật. Thành công PRG giữ filter/anchor và flash một lần.
- `OrderDAO.updateStatus` chỉ cho PENDING→PROCESSING/CANCELLED và
  PROCESSING→COMPLETED. WHERE kiểm tra trạng thái nguồn ngay lúc UPDATE,
  affected rows=1 mới thành công. COMPLETED đặt CompletedAt=SYSDATETIME().
  Trạng thái đích ngoài whitelist trả 400, ID không có/sai nguồn/race trả 409.
  Terminal không mở lại; PROCESSING không hủy. UI chỉ hiện lựa chọn hợp lệ.
- `updateAdminNote` chỉ SET AdminNote, tối đa 1000 ký tự, strip khoảng trắng ngoài,
  rỗng thành NULL; ghi đè nội dung hiện tại, không bảng log/timeline. Cho phép sửa
  ghi chú đơn terminal mà không mở lại trạng thái. Khách xem ngay tại lịch sử.
  Note lỗi được giữ trong textarea, output c:out; không cho sửa giá/snapshot.
- GET `/admin/dashboard` gọi `getStatistics()` trả Map<String,Object>, dùng một
  query GROUP BY OrderStatus/COUNT_BIG/SUM, count là Long, tổng là BigDecimal.
  Các key PENDING/PROCESSING/COMPLETED/CANCELLED, totalOrders và completedValue.
  Có 6 thẻ: tổng đơn, 4 trạng thái và **Tổng giá trị đơn hoàn tất**; chỉ cộng
  TotalAmount của COMPLETED. Chưa có đơn trả 0 sau SELECT thật; lỗi DB không trả
  số 0 giả. Không thống kê tiền đã thu hoặc thêm chart framework/job/bảng phụ.

DAO Admin giả định caller đã được Filter/Servlet kiểm tra ADMIN; hai Servlet
vẫn kiểm tra session/active/role. User bị khóa bị AuthFilter từ chối ở request
bảo vệ tiếp theo. GET chỉ đọc; dashboard không có POST nghiệp vụ.

## File và giao diện

Thêm `AdminOrderServlet`, `AdminDashboardServlet`, admin/orders.jsp,
admin/dashboard.jsp; bổ sung 3 method trong OrderDAO; menu Admin ở header;
CSS Admin actions/thống kê trong orders.css; README và test VerifyP305.java.
Không sửa Account/AuthFilter/DBContext hoặc tạo DAO riêng cho thống kê.

JSP dùng khung header/footer/styles/messages của P1, ngày theo formatter,
tiền BigDecimal qua money.tag, text qua c:out. Bảng linh kiện cuộn riêng;
thao tác/note và thẻ thống kê về một cột ở mobile. Filter giữ nguyên khi đổi
status nên đơn có thể rời danh sách hiện tại; thông báo vẫn nêu mã đã cập nhật.

  empty DB/dashboard, list mọi owner/chi tiết, 4 filter và filter sai/trùng/SQL
  injection, phân quyền/CSRF, ID/action sai, chặn nhảy/reopen/cancel PROCESSING,
  chuyển hợp lệ, CompletedAt nằm giữa mốc thời gian SQL trước/sau và không reset

  note mới hiện ở lịch sử khách, PRG/flash/filter và trạng thái terminal.

```powershell
New-Item -ItemType Directory -Path build/verify-p305 -Force | Out-Null
& 'C:\Program Files\Java\jdk-17\bin\javac.exe' -encoding UTF-8 -cp 'build/web/WEB-INF/classes;web/WEB-INF/lib/*' -d build/verify-p305 test/VerifyP305.java
& 'C:\Program Files\Java\jdk-17\bin\java.exe' '-Dfile.encoding=UTF-8' '-Dkeebforce.db.config=config/db.properties' -cp 'build/verify-p305;build/web/WEB-INF/classes;web/WEB-INF/lib/*' VerifyP305 http://127.0.0.1:18080/KeebForce
```

Chỉ chạy java nếu javac thành công; đổi config/base URL theo máy. Với DB demo
chưa có đơn, mặc định **70** checks; thêm đối số config của base thử riêng
`keebforce-p305-.../conf/keebforce-db.properties` để chạy 4 case outage (tổng 74),
không dùng config Tomcat đang chia sẻ. Có đơn trước đó thì test bỏ qua 3 case
empty; số liệu completed tính cả baseline sẵn có, không xóa đơn để tạo DB rỗng.

cho đối số config nếu chỉ muốn preview. Mật khẩu website fixture Fixture@123,
